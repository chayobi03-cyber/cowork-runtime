# 시범 예시 — 스크린샷 입력 → Topic Card 변환 (P2-02, 가상 데이터)

> ⚠️ 이 카드는 **실제 파트 업무 데이터가 아니다.** ATOMIC_PLAN.md P2-02 검증용 가상 시연.
> 이번 세션에는 실제 스크린샷 원본이 없어 "이런 화면을 캡처해 올렸다면" 가정으로 진행.

## 가정 입력

> (가정) 파트원이 매주 작성하는 "설계 검토 체크리스트" 엑셀 화면 캡처 1장을 업로드했다고 가정.
> 화면에는 항목별 체크(O/X)와 담당자 메모 열이 보인다고 가정.

## AI가 추출했을 Topic Card (Level A, 추정 결과)

- **업무/주제명**: 설계 검토 체크리스트 작성
- **왜 필요한가**: 검토 누락 방지를 위해 항목별로 확인
- **입력**: 설계 도면/변경사항
- **출력**: 체크리스트(O/X) + 담당자 메모
- **현재 문제**:
  - [ ] 반복적이라 시간이 오래 걸린다
  - [ ] 사람마다 결과가 다르다 / 실수가 잦다
  - [x] 기록이 안 남아서 나중에 확인이 안 된다 (엑셀 로컬 저장 가정 시)
  - [ ] 특정 사람만 할 줄 안다
  - [ ] 기타

## 검증 결과 (원리 확인, 실행 확인 아님)

- 실제 이미지 없이는 필드 추출 정확도 검증 불가 — 이 카드는 **원리상 가능성만** 확인한 것
- 실제 검증(P2-02 완전 완료)은 창엽님이 실제 스크린샷 1장을 다음 세션에서 제공할 때 진행
- Export Safety 관점: 스크린샷은 화면에 우연히 포함된 사번/이름 등이 특히 위험 —
  `EXPORT_SAFETY_CHECKLIST.md` 6~7번 문항이 이 케이스를 위해 신설됨 (P1-03과 연결)

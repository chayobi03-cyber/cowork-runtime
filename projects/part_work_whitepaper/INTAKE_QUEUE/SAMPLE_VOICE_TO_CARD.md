# 시범 예시 — 음성 입력 → Topic Card 변환 (P2-01, 가상 데이터)

> ⚠️ 이 카드는 **실제 파트 업무 데이터가 아니다.** ATOMIC_PLAN.md P2-01 검증용 가상 시연.

## 원본 음성(가정) 전사

> "매주 시험 데이터 정리하는데 엑셀에 붙여넣고 단위 맞추고 그래프 만드는 거 매번 똑같은
> 작업이라 30분씩 걸려요. 가끔 단위 잘못 넣어서 다시 하기도 하고."

## AI가 구조화한 Topic Card (Level A)

- **업무/주제명**: 주간 시험 데이터 정리 및 그래프화
- **왜 필요한가**: 매주 반복되는 수작업이라 시간 소모가 큼
- **입력**: 시험 원시 데이터(엑셀)
- **출력**: 단위 변환된 데이터 + 그래프
- **현재 문제**:
  - [x] 반복적이라 시간이 오래 걸린다
  - [x] 사람마다 결과가 다르다 / 실수가 잦다 (단위 오입력)
  - [ ] 기록이 안 남아서 나중에 확인이 안 된다
  - [ ] 특정 사람만 할 줄 안다
  - [ ] 기타

## 검증 결과

- Level A 5개 필드 중 4개가 원문 발화만으로 채워짐, "출력" 필드는 "그래프 만드는" 발화에서
  추론 — 발화가 짧아도 핵심 필드 대부분 자동 채움 가능함을 확인
- "왜 필요한가"는 발화에 명시적으로 없어 AI가 문맥상 추론함 — **사람 확인 필수** (자동 등록
  금지, Registry 반영 전 창엽님/파트원 확인 단계 필요)

# v0.4 Run Notes

## 목적

v0.4는 v0.3의 Tree/Schema/Node 골격 위에 실행 가능한 최소 Tool Chain을 추가한 버전입니다.

## 실행 루프

```text
Annotation Parser
→ Simple RAG Retriever
→ S2P Analyzer
→ Constraint Checker
→ Report Data Builder
→ Simple Evaluator
→ Generated Artifact Validator
```

## 현재 한계

- RAG는 keyword overlap 기반입니다. Vector DB는 아직 사용하지 않습니다.
- S2P Analyzer는 Touchstone v1 2-port 중심입니다.
- Constraint Checker는 샘플 입력값 기반입니다.
- Report는 자동 생성 초안이며, 사람 검토가 필요합니다.
- CST VBA/Python 후보 생성은 다음 단계입니다.

## 다음 후보

1. S2P 후보 부품 여러 개 일괄 비교
2. Annotation Viewer용 단순 JSON 편집 UI
3. RAG 문서 metadata registry 확장
4. CST VBA/Python script candidate template 추가
5. Tool Fit Gate 자동 평가 리포트
